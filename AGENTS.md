# Project Instructions

- Commit on the existing `dev` branch. Do not create new branches unless explicitly asked.
- Do not commit directly to `main`. Changes reach `main` through a pull request from `dev`.
- If `dev` is behind `main`, fast-forward it to `main` before committing.
- Commit or push only when asked.
- Never use Python to edit or generate files. Use Bash (sed, heredocs) or the Edit/Write tools.
